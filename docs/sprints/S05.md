Status: planned. Prerequisites: S04. Planning size: 3–5 days of focused engineering, not a delivery promise.

src/app, src/grid, src/features/shell, src/styles; NativeGridRenderingChecks.cs, NativeGridInputChecks.cs. Desktop references are relative to C:/Temp/ExcelLight/src/ExcelLite.* or its tests/docs directories; resolve exact files using the baseline inventory.

Add behavioral tests under the appropriate tests/unit, integration, parity or e2e directory. Complete the shared Definition of Done in ../Implementation-Plan.md. Update Feature-Parity with implemented status and concrete test paths; write ../handovers/S05.md from ../templates/Sprint-Handover.md. Failed feasibility or missing required verification means blocked, not complete.
