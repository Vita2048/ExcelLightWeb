# S10 — Number, date and special formats

Status: complete  
Date: 2026-11-18

## Delivered

- Home Number provides preset formats, currencies, percentage, comma style and decimal changes. The Format Cells Number dialog opens from Home, the cell context menu or Ctrl+1. It previews custom codes, negative sections, numeric options, locale-specific date and time formats, fractions and the seven regional special catalogs.
- Canvas, the accessible grid, AutoFit, the dialog sample and native filter keys share one formatter. Format-only edits can invalidate SUBTOTAL through a filter key. [F10 and F18](../Feature-Parity.md)
- Format changes are single undoable session transactions. They preserve formula source, caches and other style fields. Cancel and accepting an untouched draft preserve mixed selections. Both editors accept localized temporal input, preserve unchanged serials exactly and display serial 60 as February 29, 1900. Clipboard TSV keeps canonical numeric source. ## Remaining risks or blockers

- Browser date names come from browser locale data. Numeric dialog edits retain the existing locale tag when present. Windows regional overrides are outside the web locale contract. Explicit LCIDs preserve the captured standard regional patterns and separators.
- Scientific zero uses `0.00E+00` for the preset. The desktop formatter threw an overflow when the oracle exercised this value.
- The epoch fixtures verify the conversion contract. S19 owns production XLSX import and export.
