# S02 — Browser Python feasibility gate

Status: complete
Date: 2026-11-17

## Delivered

- Built a module worker and a test-only static site. The host sends explicit worksheet snapshots to Python through the `xl()` adapter. The two showcase workbooks supply their embedded scripts. Chart scripts receive tables from the freshly calculated reports.
- Locked 20 runtime files by SHA-256 and byte size. The 30,975,214-byte showcase closure uses Pyodide 314.0.8, CPython 3.14.2, NumPy 2.4.6, pandas 3.0.2 and Matplotlib 3.10.8. Optional PyArrow 22.0.0 and its timezone dependency add 10,020,765 bytes. The total is 40,995,979 bytes.
- Probed scalar, Series, DataFrame, 2D and PNG outputs, legacy result assignment and final expression precedence. The probe exercises Arrow IPC with a nullable table and Agg redraw of a privately serialized Figure.
- Tested under the GitHub Pages project subpath using relative asset URLs and same-origin wheels. The existing production build remains the spreadsheet scaffold. [Runtime lock](../../src/python/runtime-lock.json) · [Browser cases](../../tests/python-browser/python.spec.ts)

Fresh worker initialization including NumPy, pandas and Matplotlib was 13.8–17.1 s on Chromium, 14.2–19.8 s on WebKit and 59.7–95.1 s on Firefox. Optional Arrow initialization added 3.2 s, 3.8 s and 4.2 s respectively in one sample per engine. These are local probe observations on Windows with an AMD Ryzen 7 5800H, with three browser projects running concurrently at the start. The final run passed 15 of 15, with no retries or skips. The earlier 90-second startup deadline failed on a WebKit run with eager Arrow and a Firefox run after lazy loading. The final probe uses a 180-second startup deadline and retains the original execution deadline.

## Compatibility and follow-up

- The probe uses the tested WebAssembly package versions. Windows paths, native extensions and desktop process APIs fall outside the browser runtime. Keep JSON as the default production transport. The Arrow result demonstrates that optional IPC is viable for the tested nullable table.
- Eager Arrow loading made startup less predictable. The probe loads it on demand. A cold initialization has its own deadline. The cell deadline remains 30 seconds. S21 should expose runtime readiness and measure cold and warm latency before setting an application startup budget.
- Figure serialization was exercised inside one worker with a simple Agg Figure. S23 owns retention, restore across worker restarts, redraw of preserved artists and the cached PNG fallback. Workbook files supply script source and PNGs. Any serialized Figure cache must originate from the current trusted session.
- S20–S24 own reference preflight, consent, output validation and limits, grid/spill integration, retained figures and offline production packaging. S02 evidence applies to the named scripts and the conversions covered by the probe.
