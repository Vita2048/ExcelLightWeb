# S08 — Formula language and functions

Status: complete  
Date: 2026-11-18

## Delivered

- The worksheet uses the 31-function native evaluator after edits, structural changes and undo or redo. It publishes typed caches through the session. Unsupported formulas preserve their source and show `#NAME?`. Imported external-calculation cells with an existing cache retain that display value and return `#NAME?` to native dependents.
- The shared parser handles omitted arguments, inline array constants, reference unions and cross-sheet references. Range and array arithmetic can feed aggregates or produce scalar results. IF and IFERROR evaluate lazily. Dependency analysis includes inactive branches and reports circular references.
- DATE and date-part functions preserve serial 60. VLOOKUP preserves the desktop's exact and sorted approximate modes. SUBTOTAL covers codes 1–11 and 101–111, excludes nested subtotals and filtered rows, and applies manual row visibility for 101–111.
- Updated F05, F08, F09 and F18. [Differential tests](../../tests/parity/native-formulas.test.ts) · [Worksheet editing checks](../../tests/e2e/editing.spec.ts)

## Remaining risks or blockers

- Worksheet recalculation runs synchronously on edit. S09 adds incremental scheduling, worker execution, calculation modes and formula UI. Large-workbook latency remains unmeasured.
- SUBTOTAL uses General display keys for stored filter criteria. Styled numeric and date keys need the S10 formatter and S15 filter integration. Browser locale supplies text coercion. The differential fixture uses `cs-CZ` and does not establish Windows regional override parity.
- The implementation keeps the desktop's approximate VLOOKUP mode. The earlier architecture note listed exact-only and has been corrected.

## Editor and header follow-up

The inline editor and formula bar display function signatures and bold the active argument. The tooltip follows the caret and closes when the draft ends. Column header interiors use a down arrow and row header interiors use a right arrow. Header edges retain the resize cursors.

The initial browser run found that both editors could display a tooltip for the same draft. The active edit surface now owns the tooltip. The focused suite passed all six checks across Chromium, Firefox and WebKit. The final `npm run check` passed 540 tests and built the production app. The full production browser suite passed 64 checks with the two existing Chromium-only skips, and `npm run test:worksheet` passed all six checks. The desktop oracle, adapter probes, Pyodide and fresh `npm ci` were unrun for this UI follow-up.
