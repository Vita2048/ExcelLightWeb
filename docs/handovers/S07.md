# S07 — Structural edits and dimensions

Status: complete  
Date: 2026-11-18

## Delivered

- Sheet insertion, deletion, inline rename, move and copy are available through the ribbon and sheet tabs. Context commands apply to the clicked tab. Copies allocate independent sheet, cell, name and Python block identities.
- Row and column insertion and deletion, plus four cell shift directions, commit as detached workbook proposals. Parsed reference rewrites follow relative and absolute targets across sheets, preserve partial ranges as unions, and turn deleted targets into `#REF!`. Each edit has one Undo step.
- Row and column sizes can be set in a dialog or dragged from header edges. AutoFit works from the ribbon, header menu and double-click. Hide preserves the authored size and keyboard navigation skips hidden tracks.
- Updated F06 and F07. [Integration tests](../../tests/integration/structure-commands.test.ts) · [Browser checks](../../tests/e2e/structure.spec.ts)
