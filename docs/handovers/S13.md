# S13 — Alignment, merged ranges and ribbon parity

Status: complete  
Date: 2026-11-18

## Delivered

- Home Alignment and the Format Cells Alignment tab provide eight horizontal and five vertical modes, indents, text controls, reading order and the orientation dial. The canvas renders wrap, shrink, fill, justify, distribute, center across selection, stacked and rotated text. [Browser checks](../../tests/e2e/alignment.spec.ts)
- Merge & Center, Merge Across, Merge Cells and Unmerge expand intersecting merges and preserve the leftmost value of the first populated row in each new area. A discard confirmation protects the other values. Format Cells applies the merge, number, font, fill, border and alignment edits in one undo step. [Transactions](../../tests/integration/alignment-commands.test.ts)
- Merged selections, keyboard navigation and editing resolve to the anchor. The accessible grid reports the span. The canvas clips the full merged geometry into each visible pane and suppresses interior gridlines. [Worksheet fixtures](../../tests/worksheet-browser/worksheet-fixture.spec.ts)
- The implemented ribbon groups use the desktop order, command sizing, split controls, vector artwork and grouped dropdowns. Font and line color palettes, line style and visibility submenus, Number samples and calculation choices use themed flyouts. The Insert and Delete dialogs use the referenced four radio choices. The original desktop ICO is copied to the web favicon and is served at both tested deploy paths. [Ribbon and dialogs](../../tests/e2e/alignment.spec.ts) · [Deployment checks](../../tests/e2e/scaffold.spec.ts)
