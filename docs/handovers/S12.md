# S12 — Borders and drawing tools

Status: complete  
Date: 2026-11-18

## Delivered

- Home Borders offers all 13 presets, 13 line styles plus None, Automatic and explicit colors, and up to eight recent custom colors. Its split control repeats the last preset or tool.
- The Border tab joins the shared Format Cells draft. The preview and named edge controls edit outline, inside and diagonal borders. Style and color changes preserve mixed edges until explicitly edited. Both diagonals share a pen. [Session checks](../../tests/integration/border-commands.test.ts)
- Draw supports a straight edge or an outside rectangle. Draw Border Grid applies inside and outside edges, and Erase removes hit segments. Shared faces update together and a completed gesture is one undo step. The pencil and eraser stay active between strokes until an exit trigger. [Production browser checks](../../tests/e2e/borders.spec.ts)
- The worksheet projects stored two-axis frozen panes. Borders, draw previews and hit testing use the same projected geometry. [Geometry checks](../../tests/unit/border-geometry.test.ts) · [Frozen browser fixture](../../tests/worksheet-browser/worksheet-fixture.spec.ts) · [F12 and F20](../Feature-Parity.md)
