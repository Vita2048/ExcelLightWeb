# S14 — Names and tables

Status: complete
Date: 2026-11-18

## Delivered

- Workbook names and tables live on the immutable document. Names reject reserved identifiers and case-insensitive duplicates. A copied sheet receives independent name identities. Native formulas resolve names and `Table[#All]` / `Table[#Data]`. [Transactions](../../tests/integration/table-commands.test.ts)
- Create Table, New Name, Edit Name, Edit Table and Name Manager follow the desktop fields: Name, static Workbook scope, Comment, and Range or Refers to. Name Manager filters names and tables, applies or reverts the refers-to draft, and keeps Delete disabled for a table. The range picker accepts Enter and cancels with Escape. [Dialogs](../../tests/e2e/names-tables.spec.ts)
- Insert has a large Table button. Formulas has a large Name Manager and a small Define Name menu. Table Design shows the table name, Resize Table, the three-column style options and Blue, Green, Orange and Purple previews. The contextual tab activates on first entry and remembers that choice for the page session. Leaving a table restores the previous tab in the same paint, and the ribbon keeps its height so the grid does not jump. The resize grip and total-row menu write and rewrite `SUBTOTAL`. Shrinking a table that already has a total row moves that total up and shifts the displaced data rows down below the table. Growing it pulls occupied rows below the total into the table and moves the total beneath them. Cells beside that extent are still refused. Explicit cell fill and font override table chrome. Header labels are cached, and turning a total row on over occupied cells is refused.
- F15 and F16 are implemented in [Feature-Parity](../Feature-Parity.md). Sort, filter search, Python name rewriting and native-file mapping stay in later sprints.
