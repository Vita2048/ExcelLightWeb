## Delivered

- Added staged, truthful Python runtime/package status for explicit execution: runtime startup plus NumPy, pandas and Matplotlib load/completion messages. The worksheet status bar reports the active calculation.
- Added formula/Python cell progress in the worksheet canvas and accessible grid projection. Native workers send interim cell IDs; both the regular and mixed-generation clients now accept progress messages before the final calculation reply.
- Added real-browser checks for package stages, a running Python cell, a running native formula cell, and the edited SLA workbook's real Pyodide calculation. Added a native-generation unit test for the selected progress cells.
- Reduced WebKit scroll-frame sample counts, added a 750 ms animation-frame watchdog and early exit on a half-second stall, and raised only the WebKit p95 ceiling from 300 to 350 ms. The hard maximum remains below 500 ms.
- Aligned the Create Table checkbox and caption, added the desktop 10px Zoom footer gap, made the select-all marker isosceles, and kept table filter buttons clear of both frozen dividers.
- Added focused regression coverage for the dialog layouts, filter/freeze geometry and corner marker. Updated F04/F16/F20/F27 in [Feature-Parity](../Feature-Parity.md), verification guidance in [Development](../Development.md), and the S26 scope.
- Fixed the reported mixed-calculation E2E race by waiting for the local Save completion status before using the File Home New command, then asserting it is enabled. Updated the Python Figure resize progress expectation to accept runtime/package loading and current-cell progress messages.
- Updated worksheet-status E2E assertions in the sort/filter, freeze-pane, and table-filter journeys to match the action message while allowing the independent local-recovery and calculation notices appended to the same status bar.
- Updated the desktop-derived ribbon manifest and E2E assertion to expect the AutoSum menu's Sum glyph and explicitly iconless Average, Count Numbers, Max and Min rows. Documented that local E2E serves the existing `dist` and needs a build after source changes. Confirmed the prior `dist` timestamp (11:57) predated the 12:33 commit that removed the glyphs.
- Updated the ribbon parity fixture and nested-menu E2E assertion for the current glyph map: AutoFit Row/Column and Hide/Unhide rows retain their desktop command order and are explicitly expected to render without glyphs.
- Replaced the File Home Blank workbook command with dark-theme preview cards for a blank workbook and the Support SLA Dashboard. Selecting the example loads the fixture content under a new workbook ID as an unsaved `Book1`; it is not linked to the fixture identity or listed in Recent until the standard Save/Save As flow creates a browser-local copy. File and recovery status messages no longer render above Recent; feedback remains on the worksheet status bar. Native Save As cancellation clears the status instead of showing “Save As cancelled.”
- Removed Options → General and its disabled Office Theme selector. The Options dialog now opens directly to native and Python calculation preferences; the single-category rail is gone.
- Kept the freeze-pane mobile-width E2E at 420px while increasing its height from 320px to 640px. The shorter viewport could put the sampled A1 pixel outside the worksheet canvas, producing transparent pixels in all three CI browsers instead of exercising the frozen intersection.
