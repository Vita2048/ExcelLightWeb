# S23 — Figures, placements and redraw

Status: complete  
Date: 2026-11-23

## Delivered

- Added Figure preview actions for Save Image, place-on-sheet preview, cancel, move, eight-handle resize and one-placement deletion. Multiple placements retain independent dimensions and can cover populated cells without changing their values.
- Added a worker-only LRU retaining at most eight live Matplotlib Figures. Resize and placement redraw disposable deep copies at bounded pixel dimensions without rerunning analysis or accumulating mutations. Opaque Matplotlib counters are copied independently for Python 3.14 compatibility.
- Each placement stores its own rendered PNG fallback. Worker loss keeps cached pixels and geometry, surfaces the redraw failure, and requires the user to choose **Rebuild Figure**, which uses the existing consented Run/scheduler path.
- Kept the worker Figure identity out of workbook DTOs and native files. No pickle loading, schema change, dependency/lockfile change, desktop-source edits or backend were introduced.
- Completed F31 and F32. Real Pyodide journeys cover Save Image, distinct placement sizes, deterministic redraw, worker loss/rebuild, and Figure placement/redraw in the Sales and SLA Dashboards. Updated Architecture, Development and parity documentation.
