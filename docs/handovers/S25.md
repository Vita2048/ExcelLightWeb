## Remaining risks or blockers

- WebKit in this Playwright environment renders without GPU acceleration at 2x device pixels and does not demonstrate the 60 Hz scroll target (p95 50–60 ms, idle 30–54 ms). Chromium and Firefox do. Real Safari hardware acceptance remains unobserved.
- A single-cell edit at the exact 200,000-cell bound blocks the main thread for roughly 0.5–0.7 s because the session clones and validates the whole immutable snapshot. This is recorded, not optimized; the 10,000-cell typing budget passes. Input at maximum bounds is a known responsiveness risk.
- Windows Edge and manual screen-reader smoke checks were not run. Accessibility evidence is automated axe, focus and keyboard checks only.
- No backend, workbook schema, dependency/lockfile, desktop-source, offline or deployment change. No branch, commit or push was made.
