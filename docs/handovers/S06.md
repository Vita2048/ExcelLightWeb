# S06 — Editing, clipboard and fill

Status: complete  
Date: 2026-11-18

## Delivered

- Inline entry and the formula bar share a validated draft. Direct typing, F2, double-click, Enter, Tab, Escape and composition handling are wired into the worksheet. Invalid drafts stay on their original cells.
- Clipboard commands support in-page rich snapshots, browser TSV, Paste All, Paste Values and Paste Formulas. A denied clipboard read can fall back to the local block or a paste text dialog. Late reads cannot write into a different selection.
- Cut waits for Paste and commits movement, dependent reference rewrites and identity changes in one undoable transaction. Clear handles disjoint areas and shared borders. Fill works in all four directions, and AutoSum supports Sum, Average, Count Numbers, Min and Max.
- Arithmetic, cell references, reference unions and the AutoSum functions produce bounded derived results through the session's cache path. Updated F03, F04, F05 and F08. ## Remaining risks or blockers

- No S06 blockers. Use ribbon Paste to move a pending cut when a browser strips the rich clipboard token. Text-only clipboard events always preserve the cut source.
- The editing evaluator is intentionally bounded. Full formula semantics, worker scheduling and locale separators remain in S08–S09. Temporal input formats remain in S10. Python-bearing clipboard fixtures and Python authoring remain in S20.
