# S11 — Fonts, fills and Format Painter

Status: complete  
Date: 2026-11-18

## Delivered

- Home Font adds typed family and size controls, size stepping, bold, italic, underline and quick color actions. Format Cells shares one Number, Font and Fill draft. It adds strikethrough, superscript, subscript, accounting underlines, theme and custom RGB colors, 17 patterns and six gradient styles. One confirmation applies the edited fields in one undo step. [F11 and F33](../Feature-Parity.md)
- The worksheet and dialog use the same canvas fill and text helpers. They render authored effects and switch to system colors in forced-colors mode. AutoFit uses the same font stack as the worksheet. [Production browser checks](../../tests/e2e/appearance.spec.ts)
- Format Painter snapshots the source style pattern. A click or drag applies one transaction and preserves destination content, caches, identities and merge geometry. Enter applies to the keyboard-selected range. A double-click or the Lock control keeps the painter active across sheets. Escape and workbook adoption cancel it. [Session checks](../../tests/integration/appearance-commands.test.ts)

## Remaining risks or blockers

- Font families use a curated catalog and the local browser font stack. Unavailable names persist in the style and render using the fallback. Installed-font enumeration would require an explicit browser permission flow.
- The browser uses its canvas glyph metrics for text decoration and script placement. File Open and New controls in a running app are scheduled for S17–S18. This sprint verifies painter cancellation at the session adoption boundary.
- The gradient picker follows the desktop variant counts for each shading. The model preserves all four stored variant values.
