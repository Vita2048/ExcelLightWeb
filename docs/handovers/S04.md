# S04 — Workbook model, session and history

Status: complete  
Date: 2026-11-17

## Delivered

- F02 now has a pure TypeScript model for sparse typed cells, one-based coordinates, stable identities, worksheet state and validated workbook limits. Snapshots own deeply immutable records.
- The session applies compound cell edits and detached structural proposals atomically. Indexed deltas restore exact sparse order. Undo and redo advance the revision, retain at most 100 transactions and account for up to 64 MiB of retained deltas.
- Confirmed saves mark the captured revision's content as saved. Edits racing a save stay dirty, while undoing back to saved content is clean. Work from a replaced session is ignored.
- The versioned native worker DTO checks the full request basis before any cache commit. Native cache updates leave authored identity and history intact. [Model tests](../../tests/unit/workbook-model.test.ts) · [Session tests](../../tests/integration/workbook-session.test.ts)
