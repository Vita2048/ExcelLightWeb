# S17 — Native .exlt persistence

Status: complete  
Date: 2026-11-21

## Delivered

- Implemented the v1 native package reader and writer in `src/persistence/native`, including current and legacy field mappings, Python metadata/results/table caches/spills, figure PNG payloads and placements. Embedded Python remains inert during package load and save.
- Added bounded ZIP and workbook validation before a parsed document can be adopted: archive entry/size/traversal/duplicate checks, Python binding/cache checks, and PNG chunk, checksum and bounded scanline validation. Save validates the exported snapshot as well.
- Added desktop equality coverage for three representative fixture packages and rejection coverage for malformed or hostile inputs. A failed parse does not replace the active session document.
- Completed parity row F21. The user-facing file lifecycle and local recovery remain in S18.
