# S09 — Native dependency engine and formula UI

Status: complete  
Date: 2026-11-18

## Delivered

- Native calculation runs in a static module worker. It reuses the dependency graph on literal edits, evaluates dirty formulas and their dependents, tracks cycles through inactive branches, and shares one TODAY reading per evaluated generation. The session publishes cache batches only for the current request and workbook basis.
- Automatic coalesces edits. Manual retains existing caches and identifies stale cells in the status bar, canvas and accessible grid. Calculate Sheet includes transitive precedents across sheets. Calculate Now refreshes the native workbook. Native commands start only the native worker.
- Insert Function offers all 31 native functions and starts a cancellable draft in the formula bar or inline editor. Show Formulas synchronizes the Formulas and View controls. Browser locale determines argument separators in the editors, hints and grid; workbook source stays canonical, including quoted content and array and union syntax.
- Cache-only commits preserve the authored revision used for deferred clipboard and structure commands. [Parity changes](../Feature-Parity.md) · [Generation checks](../../tests/unit/native-generation.test.ts) · [Browser checks](../../tests/e2e/formulas.spec.ts)

## Remaining risks or blockers

- Native mode is session-local. Persistent calculation preferences are scheduled for S18. Locale tests cover browser language selection and canonical round-tripping. Windows regional overrides remain a browser adaptation.
- Each worker request still clones a workbook snapshot, and topology changes rebuild the graph. Upper-limit and percentile performance remain for S25. Formatted SUBTOTAL filter keys still depend on S10 and S15.

## Mouse range-picking follow-up

Native formula drafts now accept a mouse click for a cell or a drag for a rectangular range. Picking outlines the range and keeps the original cell as the edit target. A later pick can replace the previous reference. Cross-sheet picks escape the sheet name, and an inline draft moves to the formula bar when browsing another sheet. Enter or Escape returns to the original sheet. [Browser cases](../../tests/e2e/reference-pick.spec.ts)

`npm run build` passed both TypeScript configurations and the production build. `npx vitest run tests/unit/reference-pick.test.ts tests/unit/formula-hints.test.ts` passed three focused cases. `npm run test:e2e -- --workers=3 --grep 'formula bar picks|inline picking|invalid draft blocks|dragging beyond|formula hints follow'` passed 15 checks across Chromium, Firefox and WebKit. The full verification runs above predate this follow-up and were left unrun after it, as requested.
