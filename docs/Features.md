This is the implemented behavior inventory. Each row names the desktop behavior it preserves, how the browser implements it, and the tests that hold it. Desktop file names are provenance for the ported semantics; the desktop source is not part of this repository.

Open limitations and checks that were never run are recorded in [Known Issues](Known-Issues.md), not here.

## Formula allowlist

SUM, AVERAGE, MIN, MAX, COUNT, COUNTA, IF, AND, OR, NOT, IFERROR, ABS, ROUND, ROUNDUP, ROUNDDOWN, SUMIF, COUNTIF, LEFT, RIGHT, MID, LEN, TRIM, UPPER, LOWER, DATE, YEAR, MONTH, DAY, TODAY, VLOOKUP, SUBTOTAL. Exactly 31 names. SUBTOTAL codes 1–11 and 101–111 are required, even though the total-row picker offers a smaller list.

## XLSX losses that remain visible

Loss reports stay visible for AutoFilter/sort indicators, unsupported names/tables/charts/drawings/pivots/comments/validation/conditional formatting/hyperlinks/protection, theme/indexed colors/rich text, hidden-sheet visibility and unsupported formula caches. Export materializes existing Python scalar cells and omits code, bindings, trust and figures with a reviewed report. Full Excel round-tripping is out of scope. `.xls`, `.xlsb`, `.xlsm`, encrypted and renamed macro packages, and malformed or out-of-bounds packages are rejected; the file extension alone is not sufficient validation.
