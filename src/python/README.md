# python

S02 contains the pinned runtime lock, module worker client and Python transport adapter for the feasibility suite. The probe receives explicit worksheet snapshots and runs the existing demo scripts with an isolated namespace per run. [Development commands](../../docs/Development.md#browser-python-feasibility)

The workbook session, xl reference discovery, consent, spill application, mixed recalculation and figure retention belong to S20–S23. The probe uses JSON and base64 to measure compatibility before choosing the production transport. Its Python worker is for trusted scripts and has the browser capabilities of its origin.
